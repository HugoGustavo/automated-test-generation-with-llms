# Automated Test Generation with LLMs: A Systematic Mapping Study

Supplementary material for the systematic mapping study *Automated Test Generation with LLMs*.
It holds the full list of references mapped to each research question (RQ) and the source files for the figures
in the paper.

The paper cites only part of the literature mapped to each RQ. This repository has the **complete reference list
for every RQ**, as BibTeX, split by source database.

### `latex/`

There is one folder per research question (`rq1` … `rq12`). Each folder has one BibTeX file for each of the six
databases searched: ACM, DBLP, IEEE Xplore, ScienceDirect, SpringerLink and Wiley Online. Each file lists the
studies from that database that were mapped to the RQ. Most entries include the title, authors, year, venue,
DOI, abstract and keywords.

A study can map to more than one RQ, so it can appear in several folders. To cite all the studies for an RQ, add
that folder's `.bib` files to your LaTeX project:

```latex
\bibliography{latex/rq3/acm_classified,latex/rq3/ieee_xplore_classified,latex/rq3/dblp_classified,
              latex/rq3/sciencedirect_classified,latex/rq3/springer_classified,latex/rq3/wiley_classified}
```

## Methodology

The study starts from one broad question:

> **RQ0:** What are the key areas where LLMs can be effectively leveraged to enhance automated software testing,
> and how can they address challenges in reliability, scalability, and domain-specific adaptability?

The twelve RQs were derived in four steps (`figures/rq-derivation-flow.tex`):

1. **Query the databases.** A structured query was run in six databases and returned **8,895 records**.
2. **Filter the articles.** Inclusion/exclusion criteria, LLM-assisted screening and deduplication left
   **618 unique studies**.
3. **Extract references.** The title, abstract and keywords of each study were extracted.
4. **Generate the research questions.** Open coding of this reference base produced **six themes**. Each theme
   was split into two RQs, giving **RQ1–RQ12**.

Each study was then mapped to the RQs it contributes to. An LLM did this from the title and abstract, in twelve
independent passes (one per RQ, so each decision was a yes/no), favoring recall. The `*_classified.bib` files
in `latex/` are the result.

### Highlights

- **The field is very recent.** Publications grow sharply in 2024 and peak in 2025.
- **Most studied:** test design and execution (RQ3), comparison with traditional methods (RQ1), test validation
  (RQ2) and integration challenges (RQ9).
- **Least studied, and so open for future research:** fine-tuning (RQ6), implicit vs. explicit domain knowledge
  (RQ12), qualitative evaluation (RQ8), infrastructure constraints (RQ10) and evaluation standardization (RQ7).
